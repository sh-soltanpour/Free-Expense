items[*].active

(empty)

Values

Values are JSON literals: true, 42, "a string" (with quotes), {"a": 1}, [], null.

Good to know

Only JSON bodies fetched by the page itself (fetch / XMLHttpRequest) can be rewritten. Navigations, images and documents are untouched, and the server still receives the real request.
